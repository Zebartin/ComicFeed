## 2. 不确定项专项

- [ ] **标签中文**：B/C 后画廊页/ComicInfo 标签应为中文；冷门标签回退日文原文；里程碑标签（`10000users入り`/`10000收藏`）不出现
- [ ] **R-18 免费账号**：贴 `mode=daily_r18` 建订阅 → 有结果=免费可用；空结果且 HTTP 200 → 查账号设置
- [ ] **封面显示**：卡片封面经 `/api/cover` 显示正常（新标签页直开 i.pximg.net 链接 403 是防盗链正常现象）
- [ ] **动图 WebP**：动图榜或含动图画师 → CBZ 内 `.webp` 页可播放（取决于阅读器）；Komga 扫描后查看
