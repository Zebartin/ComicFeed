# 4KHD 源接入规格

日期：2026-11-17（Asia/Hong_Kong）。

当前状态：设计已确认，运行代码与自动验证已完成；未代填人工验收结果。

## 目标

为 ComicFeed 接入一个独立的 4KHD 源，使该站免费公开的图片图集能够通过项目现有搜索、订阅与 CBZ 下载流程使用。

前期事实与样本见 [替代源调查](../cosplay-source-research/research.md)。本规格的“全集”仅指该站公开正文及张数声明能够验证的图片集合，不保证作者原始发行版本、原始分辨率或无损图片。

## 已确认范围

- 本次只实现 4KHD，暂不接入 Cosplaytele、4KUP 或 Hentai Cosplay。
- 只接受免费公开图片，不增加登录、付费解锁、网盘压缩包获取或视频下载。
- 使用已验证的 WordPress REST API 获取文章和全篇正文，提取所有正文图片，保持正文顺序并去除重复 URL。
- 直接使用站点公开图片版本，已有样本宽约 1300 像素。图片 URL 扩展名与实际格式可能不同，保存格式应以实际内容为准。
- 不增加跨源去重；其他源和现有去重流程不在本次重构范围内。

## 接入行为

- 源名称为 `4KHD`，源键为 `4khd`，按照已有目录扫描插件方式加载，默认无需认证。
- 一篇站点文章映射为一个 Gallery，一张正文图片映射为一个 Page；统一画廊身份应保持一致，避免 ID 下载、网页链接下载和搜索结果产生同一文章的不同身份。
- 支持普通关键词搜索与关键词订阅，默认按最新文章排序；支持文章 ID 和该站文章网页链接手动下载。
- 使用现有代理、下载重试、CBZ 打包和分卷配置，不引入独立的 WordPress 框架或为后续站点预建抽象。
- 该源仅使用普通关键词，不拼接漫画源的全局语言、标签条件；搜索和订阅表单选中 4KHD 时，“全局条件”控件取消勾选并禁用，其他源保持原有能力。
- 标题保留作品信息并沿用项目归一化规则，文章日期映射为上传日期。只使用可以可靠获得的元数据，不猜测作者或虚构收藏数。
- 4KHD 收藏数在搜索、详情与持久化中均为未知值（`None`／`NULL`），收藏数筛选沿用未知值跳过该条件的行为。其他源未显式提供收藏数时保留原有默认行为。
- 保留明确的下载失败状态，不把失效响应、非图片响应或已知数量不足的结果无提示地视为完整成功。

## 已确认的决策

### Q1：尾部广告页

事实：`download.py` 当前统一调用 `strip_ads`，按图片尺寸与二维码判断尾部广告；没有现成的源级关闭入口。写真图集的宣传页也可能被判定为广告。

用户选择保留全部正文图片，包括末尾宣传页，不让广告检测改变该源的完整张数。源级广告处理控制默认为开启，仅 4KHD 关闭，其他源保持原有广告处理。

### Q2：特定画廊的增补追踪

事实：关键词订阅发现新文章；项目的特定画廊订阅另行调用 `check_updates` 并对比已有 Page ID。它们是两种不同的更新语义。

用户选择不追踪已下载文章的增补。关键词订阅发现新文章；该源的特定画廊更新检查直接返回无更新，不请求网络，也不追加 CBZ。

## 验证计划

1. 验证插件加载与连接探测确实访问公开 JSON 接口。
2. 用固定响应样本验证搜索分页、标题实体解码、全篇图片提取与顺序，不能因网页分页漏掉图片。
3. 验证文章 ID、网页链接和搜索结果的身份一致性，以及代理与重试接入。
4. 验证实际 JPEG/WebP 格式识别和非图片响应失败；按确认的广告策略验证 CBZ 张数。
5. 验证特定画廊更新检查不请求网络、不返回追加任务。
6. 对必要的公共入口改动运行相关现有回归检查，保留用户已有的其他未提交改动。

## 文档范围

源与画廊的术语沿用根目录 `CONTEXT.md`，仅将其定义明确扩展到写真图集。添加可替换的源插件是可逆变更，本轮不新增 ADR。

## 验证记录

- 插件加载、普通关键词搜索、分页终点、URL 与文章 ID 身份一致性、受保护或已知缺图响应、请求重试、非图片响应失败均有固定响应测试。
- 手动网页链接下载覆盖异步解析成功与失败：成功时使用数字文章 ID 入队，解析失败时返回明确错误且不创建下载任务。
- 用合成 JPEG/WebP 做实际 CBZ 打包：包括一个会被默认广告检测剔除的小尺寸尾页；验证 4KHD 保留该页，默认去广告行为仍可剔除它。URL 以 `.webp` 结尾但内容为 JPEG 时保存为 `.jpg`。
- 对新适配器进行真实公开 API 核实：三个人名的搜索第一页均返回 20 个结果；Machi 文章 74323、miko 文章 74506、小仓文章 71655 分别提取 129、28、73 个唯一图片链接，网页 URL 解析为相同数字 ID。
- 真实 API 核实没有下载图片正文或整套图集；完整下载、重试与 CBZ 结果使用合成图片测试，不能将其描述为真人图集完整下载已经验收通过。
- 相关自动回归结果：155 项通过，8 项排除；覆盖 4KHD、源加载、Web 入口、下载器、Pixiv、CBZ、广告处理、调度、去重与画廊 API。排除需要网络的集成／live 测试及既有 `test_download_gallery_to_cbz` 测试；未运行受用户现有 ExHentai 临时改动影响的详情测试。已有 Pixiv 测试产生一条 ZIP 重复文件名警告。
- 审查修复采用逐项 red → green 验证：截断 JPEG 不计为成功页；带收藏数条件的关键词订阅仍可下载；首次保存与再次下载都保持未知收藏数。图片验证增加完整解码，保存的图片字节不变。
- 旧库收藏数字段允许 `NULL` 的迁移只在原字段存在 `NOT NULL` 时执行；用临时测试库验证原有画廊和页面记录保留、重复启动幂等、迁移中途失败可回滚并重新执行。没有对用户现有数据库执行迁移。
- 审查修复后的相关回归：169 项通过，8 项排除，包含原有范围及数据库模型、配置、下载事件、凭证检查；排除规则与上轮一致。画廊列表将空收藏数显示为“收藏数未知”，已知零值仍显示零收藏。
- 修复后以 `HEAD`（`2c3c451f88e67cd3c5cd2fb130f70fbbcdc4a47b`）为基准进行双轴只读复审，包含相关未跟踪文件，排除用户已有 ExHentai 临时修改与下载日志行：Standards 0 项、Spec 0 项，原有三个发现均已解决。搜索、订阅、画廊模板的 JavaScript 语法检查及 `git diff --check` 通过。
